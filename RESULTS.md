# Выдача, динамика загрузки и сигнал завершения

Результаты живых прогонов (Playwright, 2026-05) в обоих режимах. Дополняет `SITES.md`
(статические селекторы форм). Здесь — **поведение выдачи, динамика, сигнал «поиск
завершён» и структура карточек результата**.

---

## 1. Режимы поиска и как они включаются

| Режим | Sletat | Tourvisor |
|---|---|---|
| **Туры** (с перелётом) | вкладка «Туры» (по умолчанию); город вылета = город | `search.php`; город вылета = город |
| **Отели** (без перелёта, только проживание) | переключатель `[data-testid="b2b.search-form.switch-search-type.hotels-btn"]` / вкладка «Отели» | город вылета = **«Без перелёта»** (`TVDepartureFilter`); отдельная точка входа `tourvisor.ru/poisk-otelej` с тем же `TV*`-фреймворком |

Вывод: на **обоих** сайтах режим — это параметр одной и той же формы, структура
результатов в обоих режимах одинаковая (отличается лишь наличие перелёта в цене).
Сравнение всегда в одном режиме: туры↔туры, отели↔отели.

---

## 2. Сигнал завершения поиска (для замера времени)

⚠️ На **обоих** сайтах число `loader`/`spinner`-элементов в DOM **не уходит в 0**
(это ленивые картинки/скелетоны) — по ним завершение определять **нельзя**.

**Tourvisor** — индикатор прогресса в процентах: `9% → 18% → … → 100%`
(текст в `.TVResultToolbar*`/`.TVResultToolbarProgress`), и `.TVProgressBar`
становится **невидимым**. Сигнал завершения:
`.TVProgressBar` не виден **И** прогресс = «100%» **И** число `.TVResultItem` стабильно.

**Sletat** — текст статуса `.search-status__tours-count`: «Нашли N туров по цене от X».
Сигнал завершения: текст статуса появился и **стабилизировался** **И** число
`.search-result__list-item` стабильно (несколько опросов подряд без изменений).

**Таймер** = от клика «Найти» до этого сигнала. Реализация: поллинг каждые ~1–2 с,
завершение при N стабильных опросах подряд (защита от промежуточных стабильных состояний),
с верхним таймаутом (~120 с).

Наблюдённые тайминги (зависят от нагрузки): Tourvisor туры ~6–90 с; Sletat туры ~35 с,
Sletat отели ~50 с.

## 3. Структура выдачи

### Sletat (туры и отели — идентична)
Список `.search-result` → `.search-result__list` → карточки `.search-result__list-item`.
**Пагинация** (`.uis-pagination__item`), ~20 карточек на страницу — НЕ бесконечный скролл.

Поля карточки (одна = отель):
| Данные | Селектор |
|---|---|
| Название отеля | `.search-result__full-hotel-name-subscription` / `.search-result-text` |
| Звёздность | количество `.search-result-category__star` в `.search-result-category__star-container` |
| Рейтинг | `.search-result-rating` (напр. «9.4») |
| Направление | `.search-result__full-group-destination` («Турция, Манавгат, 1 линия») |
| Даты/ночи | `.search-result__full-group-dates` («Заселение 06 июня», «1 ночь») |
| Цена (от) | `.search-result__full-price` |
| Кол-во операторов/туров | `.search-result__full-group-operators-amount` («3 тура от 3 оператора») |
| Развернуть туры по операторам | кнопка «Показать туры» → панель `.blinchik__operator-container` (`li.blinchik__operator-item`, цена `.blinchik__price .sr-currency-rub`) |

### Tourvisor
Карточки `.TVResultItem` (одна = отель):
| Данные | Селектор |
|---|---|
| Название (вкл. звёзды) | `.TVResultItemTitle` («Mert Seaside Hotel … 3*») |
| Локация | `.TVResultItemSubTitle` («Мармарис-центр, 20 м до моря») |
| Рейтинг | в `.TVResultItemDescription` (напр. «3.8») |
| Цена | `.TVResultItemPriceValue` + `.TVResultItemPriceCurrency` (есть `.TVResultItemOldPrice`/`.TVResultItemNewPrice`) |
| Мин. цена по операторам | панель `.TVResultToolbarOperators` → `.TVOperatorFilterColumnBody .TVOperatorFilterItemControl` (имя `.TVCheckBox`, цена `.TVOperatorFilterItemPriceValue`) |

⚠️ Панель операторов Tourvisor подгружает цены асинхронно и пересортировывает строки —
снимать атомарным `page.evaluate` после исчезновения `.TVSpinner` (см. реализацию провайдера).

## 4. Модель результата (следствие)

Глубина по режимам:
- **Туры:** оператор + минимальная цена (как сейчас) — из панели операторов.
- **Отели:** по каждому отелю — название, звёздность, рейтинг, направление, цена, кол-во операторов.

Предлагается ввести `HotelOffer` (отель) рядом с `Offer` (оператор+цена):
```python
class HotelOffer:
    provider: str
    hotel_name: str
    stars: int | None
    rating: float | None
    destination: str | None
    price: Decimal
    currency: str = "RUB"
    operators_count: int | None = None
    raw_label: str = ""
```
`ProviderResult` получает `search_mode` и, в зависимости от него, заполняет `offers`
(операторы) или `hotel_offers` (отели). Сравнение выбирает лучший/худший по цене в
рамках режима.

## 5. Поведение и риски

- **Пагинация Sletat:** для «всех» результатов нужна обработка страниц
  (`.uis-pagination__item`); для минимальной цены достаточно первой страницы (сортировка
  по цене) + статусной строки «по цене от X».
- **Антибот/капча:** за прогоны не встречены, но возможны при частоте — закладываем
  ретраи и скриншот при сбое.
- **Загрузка картинок (lazy):** даёт «шум» в счётчике лоадеров — игнорировать.
- **Tourvisor отели:** проверить наполнение результатов на `/poisk-otelej`/«Без перелёта»
  при реализации провайдера (в наивном прогоне без выбранной страны результатов не было —
  нужна корректная страна/направление).
