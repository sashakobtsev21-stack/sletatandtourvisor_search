Sletat.ru and Tourvisor — Search Module Autotests
- Автоматизированные тесты для поиска и сравнения туров на сайтах Sletat.ru и Tourvisor
- Технологии: Python, pytest, Selenium WebDriver
- Проверяет: корректность фильтров, загрузку результатов
- В результате: количество туров, минимальная стоимость, затраченное время
