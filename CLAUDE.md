# Tour Search — инструкции для агента

B2B‑инструмент сравнения туров по 5 системам: поиск+сравнение, батч‑анализ, авторизация с
ролями и тарифами, продающий лендинг. Обзор, возможности, запуск, env и структура — в
[README.md](README.md). Планы фаз и решения — в `docs/`.

## Правило: README и файл запуска всегда актуальны

После **любой содержательной доработки** — проверить и при необходимости обновить/дополнить/
переписать:

1. **`README.md`** — чтобы он отражал текущее состояние проекта.
2. **Файл запуска сервера** — `cli.py` (команда `toursearch web` → `uvicorn.run(create_app(...))`)
   и `start.bat` (Windows, собирает фронт + поднимает сервер): убедиться, что они учитывают
   изменение (новая env‑переменная, путь, зависимость, шаг сборки фронта, порядок инициализации
   приложения) и что README описывает запуск верно.

Это часть «определения готовности»: сделать ДО коммита фичи или отдельным коммитом в той же
ветке, не откладывать.

«Содержательная» = меняет видимое состояние проекта: новая фича, эндпоинт/CLI‑команда/таблица,
смена поведения, новая env‑переменная, новый модуль/страница/площадка, новые тарифы/роли.
Чисто внутренний рефактор или фикс без внешнего эффекта README/запуск не трогает.

То же касается профильных доков в `docs/` (план фазы) — отмечать готовность там, где она описана.

## Проверка перед коммитом

- Бэкенд: `ruff check src/ tests/` и `pytest -q` — зелёные.
- Фронт (если менялся): `cd frontend && npm run build && npm test` (vitest).
- Существенные фичи — сквозной смоук (threaded uvicorn + sync Playwright во временном файле, удалить после).

## Ориентиры по коду

- Площадки: `sletat, tourvisor, travelata, level_travel, ostrovok` (`src/toursearch/providers/`,
  3 последних — экспериментальные/opt‑in). Добавление — `@register_provider`, см. `docs/ADDING_A_PLATFORM.md`.
- Веб разбит по модулям: `web.py` (поиск/тесты/security‑заголовки), `web_auth.py` (3 режима/роли/
  воронка/анти‑брутфорс), `web_billing.py`, `web_jobs.py` (батч‑воркер + уведомления).
- БД — SQLite без ORM; миграции — в `storage._migrate` (ALTER COLUMN / безопасное перестроение таблиц).
- Собранный фронт `frontend/dist` раздаётся под `/app` и **gitignored** — после правок фронта пересобрать.
- Доступ к анализу: воронка гость 2 / регистрация 5 / оплата по тарифу; `admin`/`vip` — без ограничений.
