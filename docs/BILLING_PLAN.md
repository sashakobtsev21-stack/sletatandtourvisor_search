# План оплаты — КРЕДИТНАЯ модель (поиски/попытки)

Монетизация: пользователь покупает **пакеты поисков** (кредиты). Каждый запуск анализа
списывает 1. Поверх существующей авторизации (`users`/роли). Стек: FastAPI + SQLite + React.

## Принятые решения
| Вопрос | Решение |
|---|---|
| Модель | **Кредиты (поиски)**, не подписка по времени. Счётчик `users.searches_left`. |
| Бесплатно | гость (без входа) — **3** поиска; зарегистрированный — **5** (пожизненно). admin — **без ограничений**. |
| Платно | запуск анализа (право `search.run`) списывает 1 поиск. |
| Списание | **при запуске** (браузеры подняты = работа сделана). «Туров нет» = списано. Системный сбой/гейт/отмена → **возврат**. Атомарно (условный UPDATE — без гонок). |
| Тарифы (пакеты) | **30/499 · 100/999 · 500/1999 · 1000/2999** ₽ (лесенка монотонна: 16.6/10/4/3 ₽/поиск). |
| **Подписка (ГИБРИД)** | flat-fee безлимит на срок (по итогам аудита — рынок привык к подписке): **месяц 1490₽ · год 14900₽**. Пока активна — поиски не списывают кредиты. Доступ = admin ИЛИ подписка ИЛИ кредиты>0. |
| Юр-статус | самозанятый (НПД) → ИП при перерастании. |
| Провайдер | заглушка `stub` (без денег) → ЮKassa (Ф «реальная оплата»). |

## Архитектура
- **`users.searches_left`** (DEFAULT 5) — остаток. `payments(... credits ...)` — покупки (идемпотентность).
- **`billing.py`:** `has_search_access(user)` (admin ИЛИ >0), `searches_left(user)` (None=безлимит),
  `PLANS`, `FREE_CREDITS=5`, `ANON_CREDITS=3`, `PROVIDER`.
- **`storage`:** `try_consume_search` (атомарно, `WHERE searches_left>0`), `refund_search`, `add_credits`,
  `create/complete_payment` (succeeded → `add_credits` один раз).
- **Гейт:** middleware `web_auth` — `search.run` без остатка → **402** (кроме `/search/cancel`). Списание —
  в `web.py`: атомарно при старте задачи (`session.consume`), возврат в задаче при gate_failed/cancel/exception.
- **Фронт:** `BillingPage` (остаток + тарифы → купить → подтвердить); плашка «N поиск.» в шапке; 402 в поиске → подсказка.
- **Выдача вручную:** CLI `toursearch grant-credits --username … --count N`.

## Фазы
- **Ф A ГОТОВА:** кредитная модель для залогиненных (5 беспл. + покупка + списание/возврат + admin-безлимит),
  заглушка-оплата, фронт. Тесты + E2E. **Без анонимов и без реального провайдера.**
- **Ф B (анонимные 3):** разрешить поиск без входа (SPA — гостевой режим) + квота по cookie+IP + IP-лимит
  (анти-абьюз: бесплатный поиск — дорогая операция, легко обходится). Это отдельный большой кусок.
- **Ф «реальная оплата»:** `stub`→`yookassa` — checkout вернёт внешний confirmation_url (фронт уже умеет
  redirect), `/mock/confirm` → `POST /api/billing/webhook` (перезапрос-проверка + `complete_payment`).
  Нужен аккаунт ЮKassa + **публичный HTTPS (deploy)** для вебхука.

## Засады
- Анонимный поиск — дорогая (5 браузеров) и обходимая операция → вектор DoS; в Ф B защищаем cookie+IP+лимит,
  но одиночный обход остаётся (это воронка «попробовать», не защита).
- Вебхук реальной оплаты требует публичного HTTPS → завязан на deploy-историю.
- Секреты ЮKassa — env. Оферта + политика конфиденциальности — обязательны для приёма платежей.
